# AudioFollow 界面设计

参考来源是用户提供的 [UI 组件清单](https://x.com/Yur1freedom/status/2110564549560873369)，其中选取 [Appica UI](https://appica.dev/ui) 的基础组件、键盘焦点和可访问性交互作为方向。该工具主要需要开关、选择器和模式按钮，这些比仪表盘图表或营销页面组件更贴合实际用途。

实现仍是原生 WinForms，未引入网页控件、React、在线字体或 Appica 源代码。

- 颜色：墨蓝 `#1A3445`、次级文字 `#586C79`、浅蓝灰底 `#F2F6F8`、边框 `#D9E3E8`、连接绿 `#1E7051`。
- 字体：Bahnschrift 用于应用名，Microsoft YaHei UI 用于中文控件和设备名称。
- 核心信息：左侧实际播放设备，右侧实际麦克风；模式独立置顶，输入跟随可单独关闭。
- 操作：四个模式均使用原生 Button 语义，保留键盘焦点；设备选择器使用明确的可访问名称。
- 布局：设备配置默认收起，展开后可滚动；检查最小窗口、长设备名和模拟 150% 缩放。
- 刷新：只在状态变化时更新可见窗口，没有 UI 轮询定时器。

`Preview.ps1` 用模拟状态生成九张预览，并验证模式按钮、麦克风开关、设备保存和关闭到托盘。`docs/ui.png` 是模拟断开状态预览，不代表截图时的真实硬件状态。
