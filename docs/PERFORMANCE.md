# 性能验证：v1.1.0

2026-10-22，在同一台 Windows 11 电脑、窗口关闭且托盘运行时，各采样 30 秒。

| 指标 | v1.0.0 | v1.1.0 |
| --- | ---: | ---: |
| 进程 CPU 时间增量 | 0.140625 秒 | 0.000000 秒（低于本次计时精度） |
| 采样末工作集 | 58.24 MiB | 45.41 MiB |
| 采样开始 / 结束句柄 | 409 / 414 | 369 / 369 |
| 新版工作线程循环 | 未计数 | 36 |
| 新版音频完整枚举 | 未计数（旧版固定 3 秒周期） | 1 |
| 新版状态写盘 | 未计数（旧版固定 2 秒周期） | 1 |

这是一组现场观察，不能当成所有电脑的固定性能承诺。两个进程运行时长不同，工作集受 GC 和系统缓存影响；短样本中 CPU 时间为零只表示未超过计时分辨率。内存下降约 22%，具体值随运行时长变化。

## 改动依据

旧版每 20 毫秒进入后台循环，反复创建状态对象和进程包装对象；每次 HID 读取创建内核事件和非托管缓冲区，超时就取消读取。现在缓存进程 ID，保留一个挂起的 overlapped read 和它的缓冲区/事件，通过 WaitAny 同时等待音频/用户命令和 HID 数据；1 秒唤醒用于协议期限检查。取消操作只发生在重连或退出时，等待完成后再释放缓冲区。

音频枚举由 IMMNotificationClient 通知触发，另有 30 秒兜底轮询。状态变化立即保存，空闲心跳从 2 秒改为 30 秒，理论空闲写入频率减少约 93%。UI 定时器已移除；托盘图标/文本有变化才提交给 Windows，隐藏窗口不刷新。

## 可复现检查

安装运行后执行 `tools/Measure-Performance.ps1 -Seconds 30`。脚本记录 CPU、工作集、句柄和应用内部枚举/写盘计数，确认测量前后是同一个进程。可传 `-Output <path>` 保存 JSON；不要发布含本机日志或设备 ID 的诊断原文。

实机检查通过：两个输出分别切换并独立回读三个 Windows 默认角色、8 次 HID 重连后仍获得匹配 ACK 的状态响应、恢复自动模式。协议测试通过 29 项，包含被动开关事件和错误帧；UI 工具检查连接、未知、暂停、展开设置、窄窗口和模拟 150% 缩放布局。

v1.0.0 已完成接收器保持插入的物理开关机验收。v1.1.0 本轮通过真实在线状态查询和上述切换/重连检查，未再次要求人工关机，也未验证实际听音或 Windows 注销后自动启动。
